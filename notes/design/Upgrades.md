# Upgrades
## The Problem
Upgrades in games like Dark Souls and many others suck. They discourage experimentation by locking you into certain weapons/options.

Also, upgrades in a persistent roguelike don't make sense copied directly from non-run-based games. Remnant suffers from the issue that its weapon upgrades feel entirely superfluous, as the world levels with you (and eventually caps out with you). However, upgrades feel good as a player to be able to make tangible progress.

## The Solution
Universal Upgrades
- Upgrades should apply universally to all gear of a certain category, like the nail upgrades in Hollow Knight games, or the tool pouch upgrades in Silksong specifically.

Local Upgrades vs Global Upgrades
- Local upgrades only affect a single run. This allows for progress in things like weapon damage or stat benefits without capping out like Remnant and defeating the system.
- Global upgrades should be qualitative. New gear, improvements to gear beyond simple damage/defense/etc numbers. These upgrades persist between runs.
