# Consumables

## The Problem
A primary issue with consumable items in games is the common practice of hoarding items until long after they are no longer needed. This leads to stress about using consumables, particularly highly valuable and impactful ones.

## The Solution
### Rechargeable Consumables
- All consumables should operate on a recharge system ala Dark Souls' estus flask or Silksong's red tools.
  - Notably, Silksong shard cost to refill tools should be avoided
- Consumables should have their uses upgradeable in some way
  - Discover more copies?
  - Find/buy upgrades?
  - Maybe an overfill mechanic like kindling bonfires in DS1?

### Limited Equipped Items
- Only a certain number of consumables can be equipped at a time (e.g. item toolbelt)
- Toolbelt items can be swapped at checkpoints
- Toolbelt upgrades to allow more?
- Maybe toolbelt options for additional uses vs more slots vs other benefit?
